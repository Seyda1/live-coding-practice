# Linear_Equation_with_Missing_Digit Problem

## Problem Description:

You are given a linear equation as a string. Write a function that returns the integer value of x (the missing digit) that satisfies the equation without using the eval() function.

## **cases:**

### Example 1:
**Input:** "1 + x = 3"
**Output:** 2
***Explanation:** x = 3 - 1 = 2

### Example 2: 
**Input:** "4 * 10 = x"
**Output:** 40
**Explanation:** x = 4*10 = 40

### Example 3:
**Input:** "10 - x = 5"
**Output:** 5
**Explanation:** x = 10 - 5 = 5

### Example 4:
**Input:** "12 * 12 = 14x"
**Output:** 4
**Explanation:** 12*12 = 144, right side is "14x" (a three-digit number). The last digit x = 4.
